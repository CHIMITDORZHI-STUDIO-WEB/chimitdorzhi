# Агрегатор новостей «Тэнгэри» (режим «только RSS»)

Node-скрипт тянет реальные RSS-ленты бурятских и монгольских источников,
нормализует их в единый JSON-контракт и пишет файл `news.json`.
ИИ-перевод пока **не выполняется**: поле `summaryRu` = `summary`. Структура под
перевод уже заложена — см. раздел «Куда вставить перевод».

## Запуск локально

```bash
cd novosti/aggregator
npm i                      # ставит rss-parser (единственная зависимость)
node aggregate.mjs         # пишет ./news.json
```

Путь вывода настраивается (для записи прямо в репозиторий фронта):

```bash
OUT=../data/news.json node aggregate.mjs
# или позиционным аргументом:
node aggregate.mjs ../data/news.json
```

Прочие параметры через env:

| Переменная         | По умолч. | Значение                                   |
|--------------------|-----------|--------------------------------------------|
| `OUT`              | `./news.json` | путь выходного файла                   |
| `PER_SOURCE`       | `12`      | сколько свежих статей брать с источника    |
| `TOTAL_CAP`        | `90`      | общий потолок новостей                      |
| `FETCH_TIMEOUT_MS` | `20000`   | таймаут запроса одной ленты, мс            |

Устойчивость: если одна лента упала (таймаут / битый XML / 404) — скрипт логирует
`[fail] <slug>` и продолжает с остальными, файл всё равно формируется.

## Источники

Список задаётся в `feeds.json`. Активные ленты (проверены — отдают статьи):

| slug        | Источник        | Регион / язык        |
|-------------|-----------------|----------------------|
| `infpol`    | Информ Полис    | Улан-Удэ, ru         |
| `gazeta-n1` | Газета №1       | Улан-Удэ, ru (cp1251)|
| `arigus`    | Ариг Ус         | Улан-Удэ, ru         |
| `ikon`      | iKon.mn         | Улаанбаатар, mn      |
| `sonin`     | Sonin.mn        | Улаанбаатар, mn      |

В `feeds.json` также лежат **отключённые** (`enabled: false`) реально существующие
ленты (`baikal-daily`, `ulan-mk`) — они недоступны с US-IP тестового окружения,
но должны работать с российского раннера. Включите `enabled: true` и проверьте.

### Как добавить источник

Добавьте объект в массив `sources` в `feeds.json`:

```json
{
  "slug": "myslug",              // уникальный, латиницей
  "name": "Название",
  "city": "Город",
  "language": "ru",              // ru | bxr | mn | xal
  "color": "#2563eb",            // цвет метки источника на фронте
  "url": "https://site.ru/",     // главная страница источника
  "feed": "https://site.ru/rss/",// адрес RSS/Atom-ленты
  "enabled": true
}
```

Проверить ленту заранее:
`curl -sSL <feed_url> | head -c 500` — должен быть XML с тегами `<item>`.
Скрипт сам декодирует windows-1251 (как у `gazeta-n1`) по заголовку ленты.

## Контракт выходного файла

```jsonc
{
  "generatedAt": "<ISO>",
  "sources": [ { "slug","name","city","language","color","url" } ],
  "news": [ {
    "id": "<sourceSlug>-<hash>",   // стабильный sha1(url), 10 символов
    "title", "summary",            // summary — анонс без HTML, ~300 симв.
    "summaryRu",                   // = summary, пока нет перевода
    "category",                    // politics | culture | sport | regions
    "sourceSlug", "sourceLanguage",
    "publishedAt",                 // ISO, из pubDate; сортировка по убыв.
    "topicTag",                    // slug из ключевых слов заголовка
    "url", "popularity",           // 10..100, новее = выше, +5 за картинку
    "image"                        // опционально, если найдена
  } ]
}
```

Дедуп идёт по url и по нормализованному заголовку. На источник берётся не более
`PER_SOURCE` свежих, суммарно не более `TOTAL_CAP`.

## Куда вставить ИИ-перевод

Точка расширения — функция `translate()` в `aggregate.mjs`:

```js
function translate(summary /*, fromLang, toLang='ru' */) {
  return summary; // сейчас: без перевода
}
```

Чтобы включить перевод (например, монгольских `mn`-новостей на `ru`):
1. Сделайте `translate` асинхронной и вызовите API перевода (Claude/др.).
2. В `processSource` замените `summaryRu: translate(...)` на `await translate(...)`
   (переведите цикл на `for...of` с `await`, что уже есть).
3. Переводите только когда `src.language !== 'ru'`, чтобы не тратить запросы зря.
4. Ключ API добавьте секретом в GitHub Actions и в env-шаг воркфлоу.

## GitHub Actions

Файл `news-workflow.yml` — готовый воркфлоу (cron каждые 3 часа + ручной запуск),
который собирает ленту и коммитит `novosti/data/news.json`. Разместить как
`.github/workflows/news.yml`. Секретов не требует (перевода нет).
