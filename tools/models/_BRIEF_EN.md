# Английская версия каталога /en/ii-modeli/ — поле `en` в записях

В КАЖДУЮ запись своих файлов добавь поле `en` (последним полем записи, перед закрывающей `}`):

```js
en: {
  summary: 'One or two sentences, up to ~200 chars, plain business English.',
  tasks: ['3–4 business tasks', '...'],      // перевод поля tasks, тот же порядок и число
  where: ['industries / departments', '...'], // перевод поля where
  license: 'Apache 2.0',                      // перевод поля license (названия лицензий не переводить)
  developer: 'Sber',                          // только если в developer есть кириллица, иначе не указывать
  country: 'Russia',                          // перевод поля country
  sizes: 'size not stated on the model card', // только если в sizes есть кириллица, иначе не указывать
},
```

Правила:
- Переводи смысл, а не слово в слово. Аудитория — владельцы бизнеса и руководители (в т. ч. в ОАЭ и за рубежом), без жаргона.
- Ничего не добавляй от себя: только то, что есть в русских полях. Цифры, даты, названия моделей и лицензий — без изменений.
- Предупреждения сохраняй по смыслу: «не заменяет врача» → "does not replace a doctor; decisions are made by a specialist";
  «только с согласия владельца голоса» → "only with the voice owner's consent"; оговорки про юриста — "check with a lawyer".
- Упоминания «русский язык» оставляй (например, "strong Russian language support").
- Страны: Россия → Russia, Китай → China, США → USA, Франция → France, ОАЭ → UAE, Великобритания → UK и т. д.;
  «не раскрыта» / «не указана» → "not disclosed".
- В строках не используй обратные кавычки. Правь аккуратно (Edit или скрипт вставки), не переформатируй файл, другие поля не трогай.
- Для больших файлов удобно написать node-скрипт, который вставляет поле en по id из подготовленного словаря.

В конце: `node -e "const a=require('./tools/models-data.js');console.log(a.filter(m=>!m.en).map(m=>m.id).join(' '))"` —
в выводе не должно быть твоих id. Отчёт: сколько записей переведено.
