# Волна 3: новые поля для фильтров каталога /ii-modeli/

Добавь в КАЖДУЮ запись своих файлов четыре поля (сразу после поля `hardware`). Остальные поля не меняй,
кроме явных ошибок — о них напиши в отчёте. Файлы редактируй аккуратно (Edit), без переформатирования.

```js
ru: 'yes',            // 'yes' | 'no' | 'na' | 'unknown'
industries: ['retail', 'support'], // 1–4 ключа из списка ниже
ollama: false,        // true — модель есть в официальной библиотеке Ollama (ollama.com/library/...)
cpu: true,            // true — есть версия, которая реально работает без видеокарты
```

## ru — русский язык
- 'yes' — русский явно заявлен в карточке модели / документации / списке языков, ИЛИ модель российская и русскоязычная.
- 'no' — в карточке перечислены языки и русского нет, или модель только английская/китайская.
- 'na' — язык неприменим: генерация картинок/видео без текста, 3D, компьютерное зрение, табличные данные, роботы,
  разделение звука, апскейл, удаление фона, музыка (если нет вокала на русском — ставь 'na').
- 'unknown' — языковая модель, но в карточке языки не указаны и подтвердить нельзя.
Не угадывай: мультиязычность «100+ языков» без явного списка → 'unknown', если нет подтверждения русского.
Проверяй по HF карточке (https://huggingface.co/api/models/<repo> → cardData.language, и README).

## ollama
true — только если есть страница в официальной библиотеке https://ollama.com/library/<имя> (проверь WebFetch
или WebSearch «ollama library <model>»). Сборки от сообщества (hf.co/... GGUF) не считаются. Для моделей картинок,
видео, речи и т. п. почти всегда false — не трать на них проверки.

## cpu
true — если у семейства есть версия, которая практически работает на обычном процессоре без видеокарты:
языковые модели до ~4B (в квантовании), эмбеддинги, энкодеры BERT, большинство ASR/TTS небольших размеров
(Whisper small/base, Vosk, Piper, Kokoro), удаление фона, YOLO nano/small, табличные модели.
false — генерация картинок/видео, большие модели, всё, где карточка требует GPU.
