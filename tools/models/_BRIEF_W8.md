# Волна 8 (23.09.2026): чем дополняем каталог

Читать вместе с `_BRIEF.md` (формат записи, правила фактов), `_BRIEF_FIELDS.md` (ru, industries,
ollama, cpu), `_BRIEF_W7.md` (поле `quant`) и `_BRIEF_EN.md` (поле `en`). Здесь только отличия.

## Новые ключи modality
- `recsys` — рекомендательные системы: похожие товары, «с этим покупают», персональная лента,
  ранжирование выдачи в магазине.
- `anpr` — номера и транспорт: чтение государственного номера с камеры, определение типа
  транспортного средства, подсчёт потока, распознавание маркировки на кузове.
- `cad` — чертежи и проектная документация: разбор чертежей и схем, извлечение размеров
  и спецификаций, генерация CAD-моделей по описанию или эскизу.
- `acoustic` — диагностика по звуку: поиск аномалий в работе оборудования, классификация
  звуковых событий, контроль шума.

## Новое поле `langsru`
Ставится только моделям, которые работают с языками народов России (татарский, башкирский,
якутский, бурятский, чувашский, удмуртский, чеченский, тувинский и другие):

```js
langsru: true,
```

У остальных записей поле не указывается вовсе. Оно включает модель в подборку
«Открытые ИИ-модели для языков народов России». Русский язык сюда НЕ относится:
для него есть отдельная подборка и поле `ru`.

## Что важно помнить
- Аудитория — владельцы бизнеса, не инженеры. Просто, по-русски, без жаргона.
- Ничего не выдумывать: даты, размеры, лицензии — только с карточки HF / GitHub / официального блога.
- Нет открытых весов (только API) — в каталог не берём.
- Не уверен — `verified: false`, такие записи не публикуются.
- Никаких процентов точности, бенчмарков и обещаний результата.
- Для моделей распознавания номеров и любых камер, снимающих людей и машины, в summary
  обязательна оговорка: съёмка и хранение таких записей — работа с персональными данными,
  порядок согласуется с юристом.
- Для моделей диагностики по звуку: система не ставит диагноз, а даёт повод проверить узел.
- Для моделей антифрода: решение по спорной операции принимает человек.
- Для моделей языков народов России: качество сильно разное, проверять надо на своих записях.
