# AI File Sorter: локальный ИИ наводит порядок в папках без облака

>
  **Коротко.** AI File Sorter (репозиторий hyperfield/ai-file-sorter, C++ и Qt6, лицензия AGPL-3.0) предлагает новые имена и папки для фото, документов, аудио и видео. Картинки разбирает локальная визуальная модель, у документов модель читает начало текста, у музыки и видео имя собирается из тегов. Пока вы не подтвердили, ничего не переименовывается, есть пробный прогон и отмена последнего запуска. Есть версии для Windows, macOS и Linux, облако не обязательно. Но проект ведёт один человек, интерфейса на русском нет, а качество русских имён я не проверял. Перед массовым переименованием нужна копия папки.

## Папка «Сканы» и договор_финал2

В папке лежат scan_0417.pdf, IMG_2048.jpg и договор_финал2.docx, а рядом договор_финал_правки_НОВЫЙ.docx. Нужный файл бухгалтер находит по памяти, и когда он в отпуске, ищет вся контора.

Искать по тексту внутри файлов поможет [rga](/blog/ripgrep-all-poisk-po-soderzhimomu-pdf-word-arhivov-i-baz-v-papke-kompanii-2026/), а полноценный архив с распознаванием собирается в [Paperless-ngx](/blog/paperless-ngx-arhiv-dokumentov-2026/). Если в одном PDF склеена пачка документов, смотрите [разбор про DocJev](/blog/docjev-sortirovka-i-razrezanie-dokumentov-2026/). Здесь речь про сами имена и папки: что сделать с файлами до того, как они попадут в архив.

## Что за проект и что я проверил

Проверял 23.10.2026 по [репозиторию](https://github.com/hyperfield/ai-file-sorter), README и исходникам. Саму программу я не запускал, пишу по документации и коду. Репозиторий создан 30 января 2025, около 1,8 тысячи звёзд, 186 форков, не архивирован. Файл LICENSE содержит текст GNU AGPL v3. Имя и логотип защищены отдельной политикой торговых марок (TRADEMARKS.md), для форка их придётся менять.

Последний релиз 1.9.2 вышел 14 августа 2026. Последний коммит в ветке main от 18 сентября, GitHub показывает пуш в репозиторий 19 октября, в какую ветку, я не смотрел. Из 939 коммитов в main 929 сделал автор проекта, всего контрибьюторов четверо. Это проект одного человека и ему меньше двух лет. README на английском. Установщики лежат на filesorter.app, в Microsoft Store и на SourceForge, у последних релизов на GitHub файлов нет.

## Как работает и какие нужны модели

Вы выбираете папку, программа показывает таблицу: категория, подкатегория, предлагаемое имя. Можно только переименовывать, без раскладки по папкам. Из IMG_2048.jpg выходит что-то вроде clouds_over_lake.jpg, это пример из README. Документам модель даёт имя из трёх слов и до 50 знаков, по коду ей уходит фрагмент текста до 8000 знаков. Для музыки и видео имя собирается из тегов по шаблону год_исполнитель_альбом_название. Читаются PDF, docx, xlsx, pptx, odt и текстовые форматы, а старые doc, xls и ppt нет. Распознавания сканов в коде я не нашёл, так что PDF без текстового слоя, судя по всему, останется без содержимого. Такие сканы сначала нужно пропустить через [OCR](/blog/ocr-raspoznat-tekst-s-foto-2026/).

По умолчанию ставится Gemma 3 4B IT в сжатии Q4_K_M, 2,49 ГБ, для картинок плюс файл mmproj на 0,85 ГБ (размеры по Hugging Face на 23.10.2026). Есть LLaVA 1.6 Mistral 7B и Mistral 7B Instruct. Модели качаются с huggingface.co, доступность из России уточняйте. Видеокарта не обязательна: приложение берёт CUDA, потом Vulkan, иначе процессор. README советует от 8 ГБ видеопамяти для картинок, при 4 ГБ часть работы уйдёт на процессор. Требований к оперативной памяти я не нашёл.

## Облачные режимы: что уходит наружу

Можно выбрать ChatGPT по ключу OpenAI, Gemini по ключу Google AI Studio или свой OpenAI-совместимый адрес, например Ollama на вашем сервере. Тогда наружу идёт текст запросов: имена файлов, описание картинки от локальной модели и фрагмент документа. Сами картинки в удалённые клиенты по коду не отправляются. Ключ лежит в config.ini на компьютере, о шифровании в README ничего нет. Договоры и данные клиентов я бы держал на локальной модели или на своём сервере.

Отдельная находка в коде: опция «добавить дату и место в имя фото» запрашивает название места у публичного сервиса nominatim.openstreetmap.org, туда уходят координаты GPS из снимка. Фраза «всё на устройстве» к этой опции не относится.

## Предпросмотр, отмена и риски массового переименования

README советует первый прогон на копии из 20-50 файлов. В таблице каждое имя правится вручную, есть пробный режим со списком «откуда, куда». Если новое имя занято, строка пропускается, файл не затирается. Повторяющиеся предложения получают числовой суффикс.

После запуска сохраняется план отмены, команда «Правка, Отменить последний запуск» возвращает файлы. Работает она в меру возможного: если файл уже изменили, пропустит его, проверяя размер, время изменения и идентификатор. По коду отмена касается последнего запуска. В коде есть ещё история разборов в SQLite, в README она не описана.

Отмена не чинит ссылки. Книга Excel со связью на другую книгу, гиперссылка в Word, путь к файлу в карточке 1С или CRM после переименования ломаются. Защита от такого есть для папок Unity, Unreal, Godot, Blender, Git и исходников, бухгалтерских связей в этом списке нет.

## Что важно учесть

Русский язык. Он есть в списке языков имён и категорий для Gemma 3 4B и своих моделей, у Mistral 7B списка с русским нет. Интерфейс на 15 языках, русского среди них нет. Живые тесты в репозитории проверяют английский, французский, китайский и хинди. Качество кириллических имён я не измерял, цифры вам даст только пробный прогон на своих файлах.

Модель ошибается: четырёхмиллиардная модель по трём словам может назвать акт счётом. Ограничений на число файлов в README нет, но на каждый файл идёт запрос к модели, поэтому тысячи файлов на процессоре займут часы (прикидка, замеров нет). Лицензия AGPL-3.0: для внутреннего использования без доработок обязательств почти нет, но при изменении кода и доступе к нему по сети придётся открыть исходники, детали уточните у юриста. Расширение для проводника Windows живёт в отдельном репозитории и по коду связано с платным пакетом, условия я не смотрел.

## Что можно сделать уже сейчас

Скопируйте 30 файлов из «Сканов» и «Загрузок» во временную папку и прогоните программу. Посчитайте, сколько имён приняли бы без правки. Если меньше половины, переименовывать архив рано.

Договоритесь о шаблоне имени заранее, например дата, контрагент, тип документа, номер. Список разрешённых категорий (счета, акты, договоры) в программе задаётся белым списком.

Перед боевым запуском сделайте резервную копию и выпишите, что ссылается на файлы по пути: книги Excel, 1С, CRM.

Сканы сначала распознайте и положите в архив. Развернуть такой порядок под вашу бухгалтерию с проверкой, журналом и откатом могу в рамках [автоматизации бизнес-процессов](/services/business-automation/).

## Частые вопросы

### Работает ли без интернета?

После скачивания моделей да, с локальной моделью. Интернет нужен для загрузки моделей и проверки обновлений, а также для облачных режимов и определения места по фото.

### Платная ли программа?

Сайт filesorter.app называет её бесплатной и открытой, есть страница пожертвований. Код поддержки в программе скрывает напоминание о донате, по README бесплатное ядро остаётся.

### Можно ли разбирать сетевую папку?

README описывает NAS через подключённый сетевой диск в Windows или монтирование на Linux и macOS. Сам я такой запуск не пробовал.

## Коротко о главном

AI File Sorter под AGPL-3.0 предлагает имена и папки локальной моделью, показывает таблицу до применения и умеет отменять последний запуск. Минусы: один автор, нет русского интерфейса, неизвестное качество русских имён, нет защиты от поломанных ссылок в Excel и 1С.
