# claude-seo: 26 навыков и 19 агентов для SEO-аудита, что умеют

>
  **Коротко.** claude-seo (репозиторий AgriciDaniel/claude-seo) это плагин для Claude Code под лицензией MIT: набор навыков и агентов для SEO-аудита сайта. На 23.10.2026 в нём 26 навыков и 19 агентов, хотя в посте от 5 сентября называлось 25 и 18. Базовый аудит идёт без платных ключей, но нужен сам Claude. DataForSEO и Firecrawl платные. Под Яндекс набор не заточен: Вебмастера и Метрики в нём нет, Яндекс встречается только в отправке адресов через IndexNow. Читал README и код, целиком набор не запускал.

## Что внутри: 26 навыков и 19 агентов

О проекте я узнал из поста в Telegram-канале Open Source. Команда /seo audit с адресом сайта запускает, по README, до 17 агентов параллельно, и полный аудит занимает от 10 до 15 минут. Каждый берёт свой кусок: техническое SEO, E-E-A-T, разметка, карта сайта, скорость, видимость в ИИ-поиске, локальное SEO, данные Google, обратные ссылки, кластеры тем, интернет-магазин.

Те же куски запускаются по одному: /seo page, /seo technical, /seo schema, /seo geo, /seo hreflang, /seo ecommerce. Пять агентов работают на Opus, остальные на Sonnet, поэтому полный аудит съедает заметно больше лимита Claude, чем проверка одной страницы. Об этом пишет сам автор.

Цифры в посте и в репозитории разошлись: с 10 сентября вышло пять релизов, от v2.3.1 до v2.5.0.

## Кто автор и насколько проект живой

Лицензия MIT по файлу LICENSE, правообладатель agricidaniel. Репозиторий создан 7 февраля 2026 (около восьми с половиной месяцев назад). Около 19,7 тысячи звёзд, 2,9 тысячи форков, 412 коммитов в главной ветке, последний коммит и последний релиз v2.5.0 от 22 октября, архивным проект не помечен.

Автор один: 348 коммитов его, остальное разбросано между двумя десятками участников, у большинства от одного до тринадцати. Проект держится на одном человеке. Есть и коммерческий интерес: по README, участники закрытого сообщества Pro на Skool получают приватную версию с ранним доступом к новинкам.

Тесты есть: 76 файлов, бейдж в README говорит о 1077 проходящих проверках, сам я их не гонял. По названиям это проверки скриптов и безопасности, верность самих советов они не измеряют.

## Что бесплатно, а что требует ключей и денег

Плагин бесплатный, но работает внутри Claude Code, а там нужна подписка или оплаченный API. Доступ к Claude и оплату из России уточняйте.

Google. Бесплатные API (PageSpeed, CrUX, Search Console, GA4) подключаются по желанию: ключ API открывает PageSpeed и CrUX, для Search Console нужен OAuth или сервисный аккаунт. Без них, по README, Core Web Vitals будут лабораторной оценкой, а индексация выводится по самой странице.

DataForSEO. Платный API: выдача, подбор ключей, обратные ссылки, упоминания в ИИ, 23 команды. Оплата за каждый вызов, новым аккаунтам по README дают пробный баланс. Цены в README ориентировочные, у DataForSEO не сверял.

Firecrawl. Обход сайта целиком с отрисовкой JavaScript. По README бесплатно 500 кредитов в месяц, один кредит равен странице, платные тарифы от 16 долларов в месяц (по README расширения, на сайте не сверял). Banana делает картинки для превью через ключ Google AI, к аудиту это не относится.

## Яндекс: что подтверждено, чего нет

Яндекс в коде и документации упомянут только рядом с IndexNow: это список поисковиков, куда скрипт отправляет адреса новых страниц. Яндекс Вебмастера и Метрики нет, из аналитики есть GA4 и расширение для Matomo. Позиции через DataForSEO описаны для Google, Bing и Yahoo. Профили для международного SEO есть для DACH, франкоязычных и испаноязычных стран и Японии, русского нет. Журнал обновлений Google (63 записи, последняя от 21 октября) обновлений Яндекса не содержит.

Для российского сайта техническая часть, разметка и скорость полезны, а видимость в Яндексе и Алисе набор не покажет. Про них есть статья [GEO 2027: Алиса, GigaChat и нейропоиск](/blog/geo-2027-alisa-gigachat-neyropoisk/). Похожий набор я разбирал в [материале про geo-seo-claude](/blog/geo-seo-claude-proverka-vidimosti-sayta-v-otvetah-ii-poiska-2026/).

Мой [аудит собственного блога на 1500 статей](/blog/seo-audit-bloga-1500-statey-keys-2026/) построен на выгрузке из Яндекс Вебмастера, и набор её бы не увидел. Две проверки из claude-seo, валидатор разметки и оценку качества текста, я встроил в сборку блога 5 сентября, текст лицензии MIT лежит рядом. Оценка текста у меня сигнал перечитать страницу глазами, решение принимаю сам.

## Куда уходят данные

По README страницы, которые разбирает набор, попадают в Claude, как всё остальное в Claude Code. Отчёты (Markdown, PDF, HTML, Excel) лежат в папке на вашем компьютере, телеметрии по PRIVACY.md нет. Расширения отправляют адреса, домены и запросы в свои сервисы. Данные Search Console и GA4 после подключения тоже окажутся в сеансе с моделью, подрядчику стоит спросить разрешения у владельца сайта.

Плагин вешает на запись и правку файлов хук с проверкой разметки. SECURITY.md сообщает, что установка пока не сверяет подпись релиза, это обещано в версии 2.6.0. Я бы ставил через клон, прочитав install.sh.

## Где он ошибётся

Совет формулирует модель: набор даёт ей чек-листы и скрипты, а вывод по странице делает ИИ. На страницах, которые подгружают содержимое после прокрутки или клика, результат бывает шумным, автор пишет об этом сам.

Кейс с результатами в README один: собственный сайт автора, 10,8 тысячи кликов за 12 недель. Это самоотчёт, и неизвестно, дал ли рост именно набор.

Правила SEO стареют. У автора есть журнал обновлений Google с источниками. В списке изменений 2.5.0 при этом значатся правки справочных данных и удаление целевой плотности ключевых слов из трёх навыков, то есть в прежних версиях она была. Одна ошибка в robots.txt или редиректах закрывает сайт от поиска целиком, поэтому правки по совету модели без ручной проверки я не делаю.

## Что можно сделать уже сейчас

Если Claude Code есть, поставьте плагин (/plugin marketplace add AgriciDaniel/claude-seo, затем /plugin install claude-seo@agricidaniel-claude-seo и /seo setup). Нужны Claude Code версии 1.0.33 или новее и Python от 3.11 до 3.14.

Начните с /seo page на одной странице, это дешевле полного аудита, и платные ключи пока не подключайте.

Сверьте результат с отчётом «Диагностика сайта» в Яндекс Вебмастере, как описано в [статье про Вебмастер](/blog/yandeks-vebmaster-dlya-vladelca-biznesa-2026/). Расхождения покажут слепые места набора.

Если нужен человек, который пройдёт это за вас, я делаю SEO и GEO-аудит как часть [цифрового маркетинга](/services/digital-marketing/) и отдельным [аудитом сайта](/predlozheniya/audit-i-uskorenie-sayta/). Набор использую как инструмент, выводы проверяю руками.

## Частые вопросы

### Нужны ли платные ключи?

Для базового аудита нет, но нужен доступ к Claude. Расширения платные или с ограниченным бесплатным лимитом.

### Работает ли он с Яндексом?

Нет: Вебмастера и Метрики в коде нет, Яндекс есть только в списке IndexNow.

### Можно ли отдать PDF-отчёт клиенту как есть?

Я бы не стал. Оценку считает модель по правилам автора, и без ручной проверки в отчёте могут оказаться неверные пункты.

## Коротко о главном

claude-seo под MIT собирает в одном плагине десятки проверок под Google: от скорости до разметки и ИИ-поиска. Базовый аудит обходится без платных ключей, расширения стоят денег и отправляют данные внешним сервисам. Проект молодой, держится на одном авторе и написан на английском.
