# Как убрать ИИ и телеметрию из браузеров офиса через политики

>
  **Коротко.** Just the Browser (репозиторий corbindavenport/just-the-browser, лицензия MIT по файлу LICENSE) это готовые файлы политик и два скрипта установки для Chrome, Edge, Firefox и Brave. Они выключают встроенный ИИ, рекламные вставки и часть телеметрии через настройки, которые браузеры предусмотрели для организаций. Windows: файлы реестра, macOS: профили, Linux: JSON. Откат есть. Автор один, проекту девять месяцев, 3067 звёзд на 24.10.2026. Сам я проект не запускал, всё по документации и коду. Для офиса это хорошая заготовка, но строки из неё нужно прочитать и проверить на одном компьютере.

## Три сотрудника, три браузера, три набора ИИ

Условный пример. У одного сотрудника Chrome предлагает помочь написать текст прямо в поле формы с данными клиента (функция Help Me Write). У другого Edge показывает Copilot в адресной строке. Третий поставил Firefox, и у него в боковой панели чат-бот. Каждый браузер обновляется сам, и каждое обновление может принести новую кнопку с ИИ. Правило «персональные данные в ИИ не отправляем» плохо работает, пока кнопка отправки встроена в сам браузер.

Расширение, которое проверяет запрос перед отправкой, я разбирал в статье про [AImori](/blog/aimori-rasshirenie-proveryaet-zapros-k-ii-na-konfidencialnye-dannye-do-otpravki-2026/). ИИ-ассистента, который читает вкладки, в статье про [ChatGPT для Chrome](/blog/chatgpt-dlya-chrome-chitaet-vkladki-i-upravlyaet-brauzerom-chto-zashchitit-u-sotrudnikov-2026/). Настройку самой Windows через проверяемые скрипты в статье про [privacy.sexy](/blog/privacy-sexy-proveryaemye-skripty-dlya-zaschity-rabochih-mest-windows-2026/). Здесь следующий слой: настройки самого браузера, одинаковые на всех машинах.

## Что за проект и как он устроен

Проверял 24.10.2026 по [репозиторию](https://github.com/corbindavenport/just-the-browser) и GitHub API. Создан 7 января 2026 года, не архивирован, 192 коммита, из них 172 у владельца Corbin Davenport, ещё 11 человек внесли по одному-семь коммитов. Последний коммит от 23 октября, последний релиз v1.10.1 от 7 октября. Открытых обращений 16. Файл LICENSE: MIT, Copyright 2026 Corbin Davenport.

Внутри четыре папки по браузерам (chrome, edge, firefox, brave), скрипт для Windows на PowerShell, скрипт для macOS и Linux на Bash и сайт justthebrowser.com на генераторе Eleventy. Скрипт Windows скачивает файл .reg из репозитория и импортирует его через reg.exe. Для macOS это файл .mobileconfig, устанавливаемый в разделе «Управление устройством». Для Linux это JSON в каталоге политик, например /etc/opt/chrome/policies/managed или /etc/firefox/policies.

## Что именно отключается

Chrome, 19 политик (по README и install.reg): режим ИИ в адресной строке, интеграции Gemini, Help Me Write и Help Me Read, ИИ-поиск по истории, сравнение вкладок, загрузка локальной ИИ-модели, подсказки на генеративных моделях в DevTools, список покупок, промо-страницы, проверка «браузер по умолчанию». Edge, 39 политик: Copilot в адресной строке, на новой вкладке и в панели инструментов, доступ Copilot к содержимому страницы, новости MSN, спонсорские ссылки, Rewards, диагностические данные, персонализация рекламы, автозапуск Edge вместе с Windows.

Firefox: телеметрия, исследования Studies, спонсорские истории и подсказки, ИИ-элементы управления. Переводы и описание картинок в PDF остаются включёнными. AIControls работает с Firefox 149, для версий 144-148 и ESR 140.4 в файле оставлена старая политика GenerativeAI. Brave, 12 политик: ИИ-чат, кошелёк, Rewards, News, Talk, анонимная статистика и счётчик активности.

Отдельно про телеметрию Chrome. В списке из 19 строк нет политики отправки статистики использования. Если она вам нужна, ищите её в справочнике Chrome Enterprise и добавляйте сами.

## Политики или расширения

Расширение живёт внутри профиля. Пользователь может его выключить, а новая версия браузера может его сломать. Политика записана на уровне компьютера: Windows хранит её в ветке HKEY_LOCAL_MACHINE, менять которую может администратор. В Chrome, Edge и Brave значение из политики обычно нельзя переопределить в интерфейсе, на пробном компьютере это стоит проверить. В Firefox в файлах стоит Locked: false, и README прямо пишет, что любую ИИ-функцию можно вернуть в about:preferences#ai.

Расширения для проверки запросов остаются полезными: политика убирает встроенные кнопки, но не запрещает сотруднику открыть чат-бот на сайте. Политики закрывают то, что встроено в браузер, расширения и регламент закрывают остальное.

## Что важно учесть

Проект молодой и держится на одном человеке. Живой, но гарантий поддержки нет. Свежие коммиты добавляют политики Edge (18 и 23 октября). Браузер может выпустить новую ИИ-функцию раньше, чем политика на неё появится, поэтому раз в месяц список нужно сверять с обходом, как в разборе [ежемесячного IT-обхода](/blog/ezhemesyachnyy-it-obkhod-malogo-ofisa-2026/).

Файл uninstall.reg удаляет ветку Policies для браузера целиком, включая ваши собственные политики. Перед применением экспортируйте ветку. В файле Edge есть строка не про ИИ: ExtensionManifestV2Availability оставляет работать расширения старого формата Manifest V2. Для Firefox включена политика IPProtectionAvailable, то есть встроенный VPN, который при корпоративных политиках обычно заблокирован. В офисе я бы убрал обе строки и решал вопрос отдельно.

Есть открытые вопросы. Обращение №71: у одного пользователя после установки пропадало соединение в Firefox и Brave, автор воспроизвести не смог, причина не установлена. В версии 1.10.1 исправлена постоянная нагрузка процессора от CompatTelRunner.exe на части компьютеров Windows, поэтому берите её или новее. В ручной инструкции Brave для Linux опечатка в команде mkrdir, скрипт использует верную mkdir. Для Edge на Linux файлов нет.

Безопасный просмотр проект не трогает, и CONTRIBUTING обещает не принимать запросы его отключить. Политик, отключающих вход в аккаунт или синхронизацию, в файлах нет, я проверил install.reg и JSON, а профили macOS не читал построчно. У Edge есть только WebToBrowserSignInEnabled, он убирает приглашение войти при заходе на сайты Microsoft. Браузер при этом может сообщить, что настройками управляет организация (так описывают сторонние источники, в README проекта этого нет). Не используйте набор, чтобы снять защиту. Статья 19 закона 152-ФЗ называется «Меры по обеспечению безопасности персональных данных при их обработке» (по оглавлению КонсультантПлюс). Отдельную норму про браузеры я не искал, это гигиена настройки, соответствие закону она не даёт.

## Что можно сделать уже сейчас

Составьте список браузеров и версий на рабочих местах. Адреса проверки применённых политик: chrome://policy, edge://policy, about:policies, brave://policy.

Возьмите один пробный компьютер или виртуальную машину. Экспортируйте ветку реестра, скачайте install.reg, удалите лишние строки, импортируйте, перезапустите браузер и сверьте результат на странице политик. Проверьте почту, CRM, банк-клиент, печать.

В домене те же значения я бы вносил групповой политикой, а не раздавал .reg вручную. Заведите документ: какие политики, на каких версиях, кто утвердил, как откатить.

Если не хотите заниматься сами, настройку на всех компьютерах и документ я делаю в рамках [услуги по кибербезопасности](/services/cybersecurity/).

## Частые вопросы

### Нужны ли права администратора?

Да. Скрипт Windows требует запуска от администратора, на Linux нужен sudo, на macOS профиль ставится через системные настройки. Скрипт загружает код из интернета и запускает его с повышенными правами, поэтому я бы скачал файлы и прочитал их заранее.

### Сломает ли это вход в аккаунт и синхронизацию?

В файлах политик, отключающих вход или синхронизацию, я не нашёл. Исключение для Edge описано выше. Подтвердить это на ваших версиях может только пробный компьютер.

### Как вернуть всё обратно?

На Windows импортируйте uninstall.reg, на macOS удалите профиль в разделе «Управление устройством», на Linux удалите JSON-файл и перезапустите браузер.

## Коротко о главном

Just the Browser под лицензией MIT даёт готовую основу, чтобы убрать встроенный ИИ, рекламные вставки и часть телеметрии в Chrome, Edge, Firefox и Brave. Проект молодой, ведёт его один человек, политики меняются вместе с браузерами.
