# Skill Recorder: задачу записали один раз, ИИ-агент повторяет рутину

>
  **Коротко.** Skill Recorder это настольная программа Microsoft с открытым кодом (репозиторий microsoft/skill-recorder, лицензия MIT). Вы один раз делаете задачу на экране, программа пишет сессию, а GitHub Copilot превращает запись в текстовую инструкцию SKILL.md для ИИ-агента. Записываются окна, адреса страниц, буфер обмена и снимки экрана. Точных кликов и нажатий клавиш в схеме событий нет. При анализе данные уходят в облако GitHub, нужен аккаунт с доступом к Copilot. Проекту меньше трёх месяцев, результат должен проверять человек. Доступность из России уточняйте.

## Что обещал пост и что нашлось в репозитории

В посте канала GitHub Community от 25 сентября 2026 сказано, что Microsoft открыла код инструмента: задачу записывают один раз, а агент повторяет её. Ссылки на репозиторий в тексте поста не было. Я нашёл его сам и сверил по описанию и владельцу: [microsoft/skill-recorder](https://github.com/microsoft/skill-recorder), организация microsoft, описание совпадает с пересказом.

Проверял 19.10.2026. Файл LICENSE это MIT, авторские права Microsoft Corporation. Репозиторий создан 29 июля 2026, около 4,2 тысячи звёзд, 463 форка, не архивирован. Последний релиз 0.7.0 вышел 21 сентября, тогда же сделан последний коммит в основной ветке (всего их 164). После него в репозитории только обновления зависимостей до 18 октября. По списку авторов 78 коммитов у одного человека и 36 у другого, так что проект держится на двух людях. README и интерфейс на английском. Открытых обращений и запросов на слияние 44. Программу сам я не запускал, всё ниже по документации и коду.

## Что именно записывается

README говорит о «кликах», но в схеме событий (файл common/events.ts) есть только переключение приложений, смена заголовков окон, адреса страниц, буфер обмена, терминал и кадры. Кликов и нажатий клавиш там нет. Документ по Windows честно добавляет, что события интерфейса через UI Automation (фокус, нажатие кнопки) пока не сделаны.

- Окна и приложения: что активно и как называется.

- Адреса страниц: на Windows читается строка адреса, это не точный адрес вкладки.

- Буфер обмена: короткие превью скопированного текста.

- Экран: видео Chromium плюс снимок раз в секунду, сохраняется при изменении картинки или раз в пять секунд.

- Голос, если включить: расшифровка на вашем компьютере моделью Whisper, разовая загрузка около 252 МБ.

- Терминал, если открыть его из панели записи: команды и весь вывод.

Содержимого страницы (DOM) и сетевых запросов среди источников нет. Записывается то, что видно на экране и в заголовках окон.

## Как запись становится навыком

Кнопка Analyze отправляет события, кадры, текст голосового комментария и фрагменты вывода терминала в облако GitHub. Copilot восстанавливает цель и упорядоченные шаги, вы их правите. Затем можно собрать навык (файл SKILL.md с полями name, description, allowed-tools и инструкцией) либо автоматизацию по расписанию. Инструкция обобщается: записали одну заявку, в тексте будет цикл по всем. Каталоги инструментов в коде предписывают предпочитать API, консольные программы и родные инструменты агента, а не повтор кликов.

Цели такие: Scout и Microsoft 365 Copilot (Cowork), оба продукты Microsoft, и общий вариант «Agent skill», только экспорт, без настройки под конкретные инструменты. В коде о нём сказано, что проверять работоспособность вам. Copilot Studio помечен как «скоро». Claude Code в списке нет, загрузку такого файла в него я не проверял. В общем варианте каталог запрещает браузерную автоматизацию и шаги «нажми»: действие в интерфейсе должно превратиться в вызов API или команду. Для программы без API результат может оказаться пустым.

С версии 0.7.0 перед установкой можно открыть готовый SKILL.md. README уточняет: просмотр даёт видимость, а гарантий безопасности не даёт.

## Пароли, персональные данные, права агента

README просит не записывать, не вводить и не произносить пароли и ключи. Перед отправкой на компьютере идёт проверка: поиск секретов через secretlint, а из персональных данных почта, банковские карты, номера SSN и телефоны. На кадрах экрана секреты размываются через распознавание текста. Паспорта, ИНН и СНИЛС в списке детекторов не нашлись. Включена ли защита по умолчанию, я не выяснил, в README она описана как включаемая. Экран с карточкой клиента лучше считать ушедшим в облако.

Значения из записи могут попасть в сам навык: в релизе 0.7.0 упомянуты подставленные значения. Читайте файл целиком. Открытое обращение №8 в репозитории описывает случай, когда итоговый allowed-tools шире утверждённого плана. Устранено ли оно в текущем коде, я не проверял.

По описанию в каталоге, агент Scout работает на устройстве с настоящей командной строкой, не в песочнице, то есть в пределах прав вашей учётной записи. Как ограничить агента на Windows 11, разобрано в статье про [песочницу для ИИ-агента](/blog/pesochnica-dlya-ii-agenta-na-kompyutere-windows-11-mxc-i-github-copilot-2026/). Про браузерного агента с доступом ко всем сайтам писал в разборе [AIPex](/blog/aipex-rasshirenie-brauzera-delaet-rutinu-po-komandam-chto-porucit-i-gde-opasno-2026/).

## Где это не сработает

Запись не заменяет интеграцию. Если у системы есть API или выгрузка по расписанию, надёжнее подключиться к ним, как описано в услуге по [автоматизации бизнеса](/services/business-automation/). Запись нужна там, где подключиться нечем.

Макрос из [CrossMacro](/blog/crossmacro-zapis-i-povtor-deystviy-mishi-i-klaviatury-2026/) промахивается при смене разрешения экрана. Навык устроен иначе: это текст, агент каждый раз находит кнопки заново, и перенос кнопки он переживёт лучше. Зато исполнение недетерминированное, и ошибку можно не заметить. Надёжность при смене интерфейса я не измерял.

Одна запись содержит один путь. Ветки «нет такой строки» и «система выдала ошибку» в ней отсутствуют. Что стоит учесть: молодой проект, два основных автора, последний коммит 21 сентября, англоязычный интерфейс, установка из исходников командой в PowerShell. Установка идёт на Windows 11, macOS, Ubuntu, и нужен аккаунт с Copilot. Оплату и доступ из России уточняйте.

## Что можно сделать уже сейчас

Выберите задачу от 10 до 30 минут, которая повторяется каждую неделю, без платежей и паролей. Условный пример: сверка выгрузки занимает 25 минут в день, рабочих дней 21, итого около 9 часов в месяц. Цифры взяты для расчёта, замерьте свои. Заготовки навыков из регламентов есть в статье про [book-to-skill](/blog/book-to-skill-reglamenty-i-knigi-v-navyki-ii-agenta-ekonomiya-tokenov-2026/).

Запишите задачу на тестовой учётной записи и тестовых данных, голосом проговорите цель. Прочитайте SKILL.md до установки и вычеркните лишнее.

Запускайте агента под отдельной учётной записью Windows без прав администратора, с доступом только на чтение там, где запись не нужна. Первые пять прогонов результат смотрит человек. Настроить запись, проверку навыка и ограничения для агента могу в рамках услуги по [разработке ИИ-агентов](/services/ai-agents/).

## Частые вопросы

### Работает ли это с Claude Code?

Прямой поддержки в списке целей нет. Общий вариант экспортирует SKILL.md, который вы проверяете сами. Загрузку в Claude Code я не пробовал.

### Программа бесплатная?

Код под MIT, платы за программу в репозитории нет. Нужен GitHub-аккаунт с доступом к Copilot, условия подписки я не проверял.

### Можно ли записывать работу в 1С или банке?

Лучше на тестовой базе. Экран с реальными данными клиентов и счетами уходит в облако при анализе.

Skill Recorder превращает один показ задачи в текстовую инструкцию для агента, код открыт под MIT, но проект молодой и требует облака GitHub. Результат нужно читать и проверять.
