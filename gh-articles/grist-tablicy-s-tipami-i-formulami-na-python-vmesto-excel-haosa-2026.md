# Grist: таблицы с типами и формулами на Python вместо Excel-хаоса

>
  **Коротко.** Grist это таблица, где у каждого столбца свой тип, а формулы пишутся на Python и пересчитываются сами. Репозиторий gristlabs/grist-core под лицензией Apache 2.0, последний релиз v1.7.20 от 28 сентября 2026 года, ставится одной командой Docker. Права по строкам и столбцам входят в бесплатную часть. Вход через OIDC и SAML, новый ИИ-помощник и автоматизации лежат в полной редакции с ключом активации. Для учёта заказов, клиентов и склада это рабочий вариант, если вы готовы взять на себя сервер и копии.

## Почему учёт в Excel ломается

Знакомая картина: файл заказов лежит в общей папке, рядом копия «заказы_финал2». Двое правят одновременно, одна версия затирает другую. В столбец суммы кто-то вписал «около 5 тысяч», и итог по месяцу не сходится. Формулу протянули не до конца. Склад ведёт один человек, менеджер видит его цифры с задержкой. Любой сотрудник может исправить чужую ячейку, и никто не узнает, кто и когда.

Этот сценарий я разбирал в статье про [Excel как спасение и тупик](/blog/excel-spasenie-i-tupik-2026/). Excel сам не знает, какие данные должны лежать в ячейке, и проверить это некому.

## Что даёт Grist и что я проверил

8 октября 2026 года канал GitHub Radar рассказал про gristlabs/grist-core. Я сверил заявленное с [репозиторием](https://github.com/gristlabs/grist-core) и [документацией](https://support.getgrist.com/). Лицензия Apache 2.0 указана в LICENSE и package.json, репозиторий не в архиве, последняя отправка кода 8 октября. Документ хранится в формате на основе SQLite, один документ это один файл.

Типы столбцов: текст, число, целое, переключатель, дата, выбор из списка, ссылка на запись другой таблицы, вложения. Нюанс: Grist не запрещает вписать неподходящее значение, а подсвечивает ячейку ошибкой, и зависимые столбцы тоже показывают ошибку.

Связи и формулы. Заказ ссылается на клиента, карточка клиента показывает его заказы. Формулы поддерживают полный синтаксис Python и много функций в стиле Excel, пересчёт идёт при изменении ячеек, на которые формула ссылается.

Виджеты: таблицы, карточки, диаграммы, календарь, сводные таблицы, встроенные формы. Виджеты связываются: выбрали клиента в одном, во втором видите его заказы.

Права и история. Правила доступа задаются для таблиц, строк и столбцов, например скрыть телефоны от курьера. Вкладка «Активность» показывает последние изменения, снимки документа можно сравнить и откатить, срок их хранения документация не называет. Чтобы всё это работало, Grist должен знать, кто вошёл.

## Редакции, развёртывание и копии

Разделение описано в README. В grist-core есть Python-формулы, права по строкам и столбцам, формы, REST API, вебхуки, SCIM, старый ИИ-помощник по формулам. Только в полной редакции с ключом: вход через OIDC и SAML, новый Assistant, автоматизации, уведомления, встроенный MCP-сервер. Ключ бесплатен для организаций с общими финансами меньше 1 миллиона долларов в год, заявку проверяет человек до 5 рабочих дней, срок год, поддержка через форум и Discord. Образ gristlabs/grist содержит и закрытые расширения, они спят, пока в админке не включена полная редакция. Образ gristlabs/grist-oss собран только из свободного кода.

Запуск по README: docker run -p 8484:8484 -v $PWD/persist:/persist -it gristlabs/grist. Ключ первого входа печатается в логе контейнера. Без тома persist данные не сохранятся.

Вход. «Sign in with getgrist.com» и заголовки прокси работают во всех редакциях. В README сказано, что проверялись Authentik, Auth0 и вход Google или Microsoft через Dex. В документации по OIDC примеры для GitLab, Gitea, Auth0 и Keycloak, Google там нет: прямой вход через Google не подтверждён.

Копии. Документы лежат в каталоге docs внутри persist, плюс служебная база home.sqlite3, так что копируется том. Для автоснимков документация советует S3-совместимое хранилище с версионированием, рекомендован Redis. Отдельный документ скачивается файлом grist, внешние вложения в него не попадают.

Размеры. Страница лимитов описывает хостинг Grist: 5 000 строк на бесплатном тарифе, 100 000 на Pro. Для вашего сервера эти числа не подтверждены. Рекомендация для всех тарифов: документ до 20 МБ, дальше возможны тормоза.

## Что важно учесть

ИИ-помощник требует внешнюю модель. По документации, он отправляет в OpenAI вопрос и схему документа, то есть названия столбцов, по умолчанию модель gpt-4o. Строки таблицы там не упомянуты, но схема тоже может быть чувствительной. Другую модель, в том числе размещённую у вас, подключить можно. Если персональные данные попадают в названия или вопросы, это вопрос по [152-ФЗ](/blog/152-fz-dlya-chat-botov-i-messendzherov-2026/), решайте его с юристом.

Сложную логику одними формулами не закрыть: согласования, рассылки и интеграции требуют вебхуков, API и кода. Автоматизации внутри Grist есть только в полной редакции. Пользователь с правом менять структуру пишет формулы, а они правилами доступа не ограничены, это сказано в документации.

Сервер, обновления и копии остаются на вас. Когда выходит новая версия, её нужно поставить и проверить на копии данных. Если сервер упадёт, а копию никто не проверял, восстанавливаться придётся вручную.

## Что можно сделать уже сейчас

Перенесите за вечер одну таблицу заказов. Поднимите Grist в Docker, импортируйте файл Excel и проверьте тип каждого столбца: сумма числом, дата датой, статус выбором из списка. Вынесите клиентов в отдельную таблицу и свяжите заказы ссылкой. Добавьте столбец с формулой, например сумму со скидкой. Настройте правило: менеджер видит только свои заказы. Скачайте файл grist и убедитесь, что он открывается. Если за вечер получилось, остальные таблицы переносятся тем же путём.

Для компании я переношу Excel в Grist, проектирую таблицы и связи, настраиваю права, вход и резервные копии. Это часть [автоматизации бизнеса](/services/business-automation/).

## Частые вопросы

### Grist полностью бесплатный?

Код grist-core бесплатный по Apache 2.0. Полной редакции нужен ключ, для организаций до 1 миллиона долларов общих финансов он бесплатный, выше нужна платная лицензия.

### Можно ли входить через Google?

Прямая настройка в документации не подтверждена. В README проверенным назван вход Google или Microsoft через Dex.

### Откроется ли файл без Grist?

Документ это файл SQLite, числа и текст читает любой инструмент для SQLite. Выгрузка в Excel и CSV тоже есть.
