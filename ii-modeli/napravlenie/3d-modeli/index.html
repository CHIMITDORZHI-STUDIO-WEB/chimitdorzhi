Открытые нейросети для создания 3D-моделей

3D-модели создают объёмные объекты по фото или описанию: для интерактивных витрин, игр, дополненной реальности и прототипов. Это сокращает работу 3D-дизайнера на черновом этапе. Проверьте, в каких форматах модель отдаёт результат, насколько качественны текстуры и что разрешает лицензия.

DUSt3R / MASt3R

NAVER LABS Europe · Франция (NAVER, Южная Корея)

Семейство, с которого началась 3D-реконструкция «в один проход» по паре или набору фото без калибровки камер. MASt3R добавил сопоставление точек и масштаб, MUSt3R и BLASt3R — работу с видео.

  • 3D-сцена по нескольким фото без калибровки
  • Сопоставление точек между снимками
  • Построение карты по видео (SLAM)
