Открытые модели для перевода запросов в SQL

Эти модели превращают вопрос обычными словами в SQL-запрос, чтобы руководитель мог получить цифры из базы без помощи аналитика. Качество сильно зависит от того, насколько понятно описана структура ваших таблиц. Смотрите на поддержку вашей СУБД, лицензию и продумайте доступ только на чтение.
