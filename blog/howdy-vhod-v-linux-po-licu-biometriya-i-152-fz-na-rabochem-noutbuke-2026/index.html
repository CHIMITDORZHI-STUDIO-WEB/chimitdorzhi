Howdy: вход в Linux по лицу и 152-ФЗ на рабочем ноутбуке

Howdy позволяет входить в Linux, делать sudo и разблокировать экран по лицу. Проверил по репозиторию: лицензия MIT, последний релиз 2020 года, версия 3.0.0 лежит в master без тега. Разобрал оговорку авторов о безопасности, вопросы 152-ФЗ (без выводов, это к юристу) и схему политики с пилотом на одном ноутбуке.

Howdyвход по лицубиометрия152-ФЗLinux
Коротко. Howdy (репозиторий boltgolt/howdy, лицензия MIT) даёт Linux вход по лицу в стиле Windows Hello через PAM: экран входа, блокировка, sudo. Состояние на 19.10.2026: последний релиз v2.6.1 вышел 2 сентября 2020 года, последний коммит в master датирован 22 июня 2025 года, там записана версия 3.0.0, но тега и релиза под неё нет. Авторы пишут прямо: вход по лицу удобнее пароля, надёжность у него ниже. Лицо сотрудника ещё и вопрос по 152-ФЗ, ответ на него даёт юрист. Моя схема: пароль или ключ по умолчанию, лицо по письменному согласию, пилот на одном ноутбуке.

Услуга по кибербезопасности: пилот входа по лицу и политика для Linux-ноутбуков

Сотрудник смотрит в камеру, и ноутбук открывается

Открыл крышку, посмотрел в камеру, система вошла без пароля. Владельцу бизнеса сразу хочется спросить, насколько это надёжно и что скажет закон о персональных данных. Пост GitHub Radar от 18.10.2026 про Howdy я проверил по репозиторию, вики и закону на consultant.ru.

Что за проект и в каком он состоянии

Проверял 19.10.2026 репозиторий boltgolt/howdy. Файл LICENSE содержит лицензию MIT, коммерческое использование она разрешает. Репозиторий создан в 2018 году, не архивирован, около 7,8 тысячи звёзд.

Теперь главное. Последний опубликованный релиз v2.6.1 датирован 2 сентября 2020 года. Код в master двигался позже: последний коммит от 22 июня 2025 года, он на 273 коммита впереди релиза. В debian/changelog для этой точки записана версия 3.0.0: PAM-логика переписана на C++, добавлен одновременный ввод пароля и распознавание лица. Тега 3.0.0 и релиза на GitHub нет. Свежих коммитов за 16 месяцев я не нашёл, хотя звёзды и новые обращения в октябре 2026 года продолжают появляться.

В README у Arch Linux стоит пометка «Maintainer wanted», а у Fedora сказано, что после удаления Python 2 в Fedora 41 установка может падать. Какую версию вы получите из PPA или COPR, я не проверял: уточняйте.

Как это работает и где лежит лицо

Howdy встаёт модулем в PAM, общую систему проверки входа в Linux. По README он работает везде, где иначе нужен пароль. Пакеты есть для Debian, Ubuntu, Arch, Fedora и openSUSE. Команда sudo howdy add запоминает лицо.

Распознавание построено на библиотеке dlib. Детектор находит лицо (по умолчанию классический HOG, тяжёлая CNN-модель включается параметром use_cnn и просит видеокарту), нейросеть превращает лицо в вектор чисел. Скрипт add.py пишет этот вектор в JSON-файл, фотография не сохраняется.

Файл лежит локально, отдельный на пользователя. По умолчанию сборка кладёт его в подпапку models каталога настроек, на практике /etc/howdy/models/имя.dat. Отправки по сети в Python-файлах, которые я прочитал, нет. Графическую часть howdy-gtk я не смотрел. Права на файл add.py явно не задаёт, при этом в скрипте установки для Debian есть chmod 755 для /etc/howdy. Что вышло у вас, покажет ls -l. Команда howdy clear удаляет файл обычным os.remove, без затирания.

Вики пишет, что Howdy должен работать почти с любыми ИК-камерами, и ведёт список проверенных ноутбуков. Для части моделей нужна утилита linux-enable-ir-emitter, иначе подсветка не включается. Работает ли обычная веб-камера, не подтверждено.

Что авторы пишут о безопасности

В README есть раздел «A note on security». Пересказываю близко к тексту: пакет не так надёжен, как пароль, и таким не станет. Обмануть его труднее обычного распознавания, но похожего человека или хорошо напечатанного фото может хватить. Howdy делает вход быстрее и удобнее, безопаснее он его не делает. Последняя строка раздела: «DO NOT USE HOWDY AS THE SOLE AUTHENTICATION METHOD FOR YOUR SYSTEM».

ИК-камера, на мой взгляд, снижает риск: экран телефона и цветная распечатка в инфракрасном кадре выглядят иначе. README этого не утверждает, и гарантией это не служит. Проверки живости в документации я не нашёл. Почему фото обманывает такие системы, я разбирал в статье про открытый SDK распознавания лиц.

С паролем Howdy сочетается так. Файл PAM для Debian содержит правило success=end default=ignore: успех лица завершает проверку без пароля, неудача пропускается, и система спрашивает пароль. Лицо по умолчанию заменяет пароль, второго фактора оно не добавляет. По вики, для схемы с двумя факторами слово sufficient нужно заменить другим, готового рецепта там нет. Шифрование диска Howdy не заменяет: PAM работает после загрузки, пароль на диск остаётся.

Лицо сотрудника и 152-ФЗ

Подтверждено на consultant.ru. Статья 11 152-ФЗ (страница показывает редакцию от 26.07.2026): биометрические персональные данные это сведения об особенностях человека, по которым можно установить личность. Обрабатывать их оператор вправе с письменного согласия, кроме случаев части 2. Предоставление биометрии не может быть обязательным, отказ не даёт права отказать в обслуживании (части 1 и 3). Отдельно действует закон 572-ФЗ. В его оглавлении есть статья 13 про доступ в помещения организаций и статья 15 про обработку биометрии вне единой биометрической системы. Содержание этих двух статей я знаю по вторичному пересказу.

Чего я не утверждаю. Являются ли числа, которые Howdy хранит на ноутбуке, биометрическими данными в смысле статьи 11. Считается ли это обработкой со стороны работодателя, если файл лежит только у сотрудника. Касаются ли такой схемы статьи 13 и 15. Всё это вопросы к юристу. Общий разбор в статье про биометрию и ЕБС.

Как построить политику

По умолчанию вход по паролю или ключу, лицо включается отдельным решением. Вход без паролей на сайты даёт passkeys. Лицо только по добровольному выбору, отказ без последствий. Согласие письменное, текст согласует юрист. Вектор остаётся на ноутбуке и на сервер компании не копируется. Сохранение снимков входа выключено: параметры save_failed и save_successful в config.ini по умолчанию false. Пароль остаётся, диск зашифрован. При увольнении и по просьбе сотрудника выполняется howdy clear, этот пункт идёт в чек-лист кибергигиены команды.

Что можно сделать уже сейчас

Возьмите один ноутбук с ИК-камерой, проверенные модели перечислены в вики проекта. Установите Howdy, добавьте своё лицо, на время правки PAM держите второй терминал с root-доступом, чтобы не запереть себя.

Прогоните проверку на подмену: экран телефона с вашим фото, бумажная распечатка, лицо коллеги. Результат запишите и посмотрите ls -l файла модели.

С результатами идите к юристу с вопросами из раздела про 152-ФЗ. Пилот, политику входа и текст для юриста могу подготовить в рамках услуги по кибербезопасности.

Частые вопросы

Можно ли ставить Howdy на рабочие ноутбуки?

Лицензия MIT разрешает. Смущает состояние проекта, поэтому я начинаю с пилота и оставляю пароль.

Заменит ли лицо пароль и шифрование диска?

Нет. Авторы запрещают использовать Howdy как единственный способ входа, а диск расшифровывается до загрузки PAM.

Нужно ли согласие сотрудника?

Статья 11 152-ФЗ требует письменного согласия на обработку биометрии. Применима ли она к файлу на ноутбуке сотрудника, решает юрист. Я в любом случае беру письменное согласие.

Коротко о главном

Howdy под лицензией MIT даёт Linux вход по лицу через PAM, но релиз вышел в 2020 году, а версия 3.0.0 лежит в master без тега. Авторы называют инструмент удобством с надёжностью ниже пароля. Для бизнеса остаётся политика: пароль или ключ по умолчанию, лицо по письменному согласию, вопрос по 152-ФЗ у юриста.
