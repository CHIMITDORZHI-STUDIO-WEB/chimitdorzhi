Flint от Microsoft: ИИ рисует графики для отчётов сам

Microsoft Research выложила Flint: язык, на котором ИИ-агент описывает график в десяток строк, а оси, подписи и оформление подбирает сам. Разбираем, что уже работает в версии 0.5.1, как подключить к агенту и где проект пока сырой.

FlintграфикиавтоотчётыMCP
Коротко. Microsoft Research выложила в открытый доступ Flint: язык описания графиков для ИИ-агентов. Агент пишет короткую спецификацию из десятка строк, а Flint сам подбирает оси, отступы, подписи и тему оформления. Результат собирается в Vega-Lite, ECharts, Chart.js, Plotly или в обычный график Excel. Лицензия MIT, версия 0.5.1, проект молодой. Собственнику без аналитика это даёт отчёт с готовыми картинками вместо вечера над Excel.

Вечер над графиками вместо решений

У владельца магазина или сервиса данные лежат в трёх местах: выгрузка из кассы, таблица с рекламой, Excel с планом. Чтобы увидеть динамику, нужно выбрать тип графика, подписать оси, поправить масштаб и убрать налезающие подписи. На один график уходит полчаса, на недельный отчёт с шестью графиками весь вечер. Аналитика в штате нет, поэтому отчёт выходит раз в месяц.

ИИ-агент давно умеет посчитать цифры. С картинкой у него хуже. Когда модель сама пишет подробный код графика, подписи слипаются, а легенда съедает половину картинки. Если каждый пятый график выходит испорченным, в рабочий процесс его не поставить. Flint забирает эту часть работы у модели.

Что такое Flint

Репозиторий: microsoft/flint-chart на GitHub. Он создан 13 мая 2026 года, последние изменения от 1 октября 2026, звёзд около 4,3 тысячи. Лицензия MIT, в коммерческих проектах использовать можно. Последний релиз, 0.5.1, вышел 14 августа 2026 года.

Идея в разделении труда. Агент описывает смысл: какие поля есть в данных, что в них лежит и какой тип графика нужен. Для этого у Flint есть больше 70 смысловых типов: цена, температура, страна, ранг и так далее. Дальше работает обычный детерминированный компилятор, без нейросети. Он смотрит на данные и решает, сколько места дать подписям, нужна ли легенда и как сгруппировать столбцы.

Пример из README: у агента есть таблица с весом и расходом машин. Он указывает тип «Scatter Plot», поля для осей X и Y, поле для цвета и базовый размер. Про шрифты и расстояния агент ничего не пишет.

Темы оформления и куда это выводится

Оформление вынесено в отдельный слой ThemeSpec. В комплекте десять готовых тем, среди них Economist, Swiss, Pop, McKinsey и New York Times.

Один входной файл собирается в пять форматов:

  • Vega-Lite, ECharts, Chart.js и Plotly: для сайта, панели или веб-приложения;
  • Excel: по README, 18 родных шаблонов, и график в таблице остаётся редактируемым, бухгалтер может подправить его руками.

Последний пункт мне нравится больше остальных. Файл можно переслать партнёру, и он откроется без установки чего-либо.

Как подключается к агенту

Подключение есть в двух вариантах. Первый, MCP-сервер: локально он запускается командой npx -y flint-chart-mcp, нужен Node.js 18 или новее. Есть и размещённый сервер Microsoft по адресу flint.data-formulator.ai/mcp, его можно добавить в Claude или VS Code как пользовательский коннектор. Из обзоров следует, что у сервера два инструмента: один рисует картинку PNG, второй открывает интерактивный просмотр, где можно сменить цвета и сортировку. Про MCP я писал отдельно: MCP простыми словами.

Второй вариант для агентов без MCP: готовый навык в папке agent-skills репозитория. Он учит модель писать спецификации Flint. Если вам нужна только библиотека, ставится она через npm install flint-chart, а для показа в браузере понадобятся ещё vega, vega-lite и vega-embed.

Как это выглядит в автоотчёте

Возьмём сеть кофеен. Утром агент забирает выгрузку продаж за вчера, считает выручку по точкам и среднюю цену чека, сравнивает с прошлой неделей и пишет три короткие спецификации: столбцы по точкам, линия выручки за 30 дней, структура продаж по категориям. Flint рисует всё в одной теме, и в Telegram приходит сообщение с тремя картинками и парой строк текста.

Так же работает реклама: расход, заявки и цена заявки по каналам. Или склад: остатки по группам. Отчёты такого рода я уже собираю, обычно картинкой в мессенджер: автоотчёты руководителю в Telegram. Если нужна живая панель с фильтрами, смотрите разбор Metabase. Flint закрывает другой случай: быстро собрать отчёт из выгрузки и разослать людям.

Оценка для примера: два-три часа в неделю на отчёт с шестью графиками дают за месяц целый рабочий день.

Что важно учесть

Проект молодой. Ему меньше пяти месяцев, версия ниже единицы, списка известных ограничений в README нет. По обзорам, Microsoft использует его внутри своего инструмента Data Formulator. Но стабильности на годы вперёд никто не обещает: формат спецификации может поменяться.

  • Темы сейчас применяются в основном к Vega-Lite. На ECharts, Chart.js и Plotly оформление скромнее, это видно из README.
  • Типы графиков: по обзору Better Stack, карт, трёхмерных графиков и сетевых диаграмм нет, сложные наложения тоже ограничены. Обычные для бизнеса столбцы, линии, круги и точки есть.
  • Русские подписи: в документации про кириллицу и шрифты ничего не сказано. Перед запуском нужен тест на реальных названиях точек и месяцев.
  • Python-версия пока только предварительная, из исходников. Основная работа идёт на JavaScript и TypeScript.
  • Размещённый MCP-сервер Microsoft: где именно обрабатываются и хранятся данные, документация не говорит. Коммерческие цифры я бы гонял через локальный запуск.
  • Спецификацию пишет модель и может выбрать не то поле, поэтому цифры в отчёте сверяют с источником.

Что можно сделать уже сейчас

  1. Возьмите один отчёт, который вы собираете руками чаще всего. Лучше всего подходит недельная выручка или заявки с рекламы.
  2. Подключите локальный MCP-сервер Flint к своему ассистенту и дайте ему выгрузку в CSV. Проверьте, как отрисуются русские подписи.
  3. Выберите одну тему и зафиксируйте её. Отчёты станут узнаваемыми.
  4. Когда картинки вас устроят, поручите агенту присылать их по расписанию в Telegram или на почту. Тогда график перестанет быть вашей задачей.

Частые вопросы

Flint заменяет Metabase и другие BI?

Нет. BI хранит подключения к базам, фильтры и права пользователей, а Flint рисует график по готовым данным. Они дополняют друг друга: BI для постоянной панели, Flint для отчёта, который агент присылает сам.

Нужно ли уметь программировать?

Чтобы просто пользоваться через ассистента, нет. Чтобы подключить источники и расписание, программист нужен.

Можно ли получить график в Excel?

Да, у Flint есть экспорт в родные графики Excel. По README таких шаблонов 18, и график в файле можно править вручную.

Коротко о главном

Flint снимает с ИИ-агента самую капризную часть работы с графиками: расстановку осей, подписей и отступов. Проект открытый, с лицензией MIT, но ему меньше пяти месяцев, и по русским подписям и приватности размещённого сервера нужны свои проверки. Для автоотчётов из выгрузок он подходит уже сейчас, если не ждать от него карт и сложных диаграмм.
