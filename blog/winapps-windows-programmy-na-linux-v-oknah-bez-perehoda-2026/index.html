Офис на Linux, но нужен Word или Photoshop: что даёт WinApps

WinApps запускает Windows в виртуальной машине и выводит отдельные программы, например Word или Photoshop, в окнах рядом с обычными приложениями Linux. Разбираю, что проект требует по лицензиям и железу, где могут не заработать токены и ключи и как проверить всё на копии.

WinAppsLinuxвиртуализациямиграция с Windows
Коротко. WinApps это бесплатный набор скриптов для Linux. Он запускает Windows в виртуальной машине (Docker, Podman или libvirt) и выводит отдельные программы, например Word или Photoshop, в обычных окнах рядом с родными приложениями. Для офиса, который уходит с Windows, это способ оставить две-три нужные программы без Windows на каждом компьютере. Лицензии на Windows и Office остаются на вас, виртуалка съедает память, а ключи и токены могут не заработать. Проверять нужно на копии.

Перевести офис на Linux и сохранить нужные программы

Уйти с Windows мешают две-три программы

Офис переводят на Linux. Двадцать человек живут в браузере, почте и LibreOffice. Но у бухгалтера есть таблицы с макросами в Excel, у дизайнера Photoshop, а клиенты присылают файлы Word со сложной вёрсткой, которые в другом редакторе «едут». Из-за этих трёх мест переход откладывают.

Что делать с парком, когда у Windows 10 закончились обновления, я разбирал в статье про Windows 10 без обновлений, а переезд на отечественную систему в статье про миграцию на Astra Linux. WinApps закрывает остаток: несколько программ, которым пока нет замены.

Как это устроено

Проект лежит в репозитории winapps-org/winapps. По README он делает четыре вещи. Запускает Windows в виртуальной машине Docker, Podman или libvirt. Спрашивает у Windows список установленных программ. Создаёт для выбранных ярлыки в меню Linux. И выводит их окна через FreeRDP, поэтому Word стоит в панели задач рядом с Firefox, а не внутри рамки с рабочим столом Windows.

Домашняя папка Linux видна внутри Windows как \\tsclient\home. В файловом менеджере Nautilus файл можно открыть в Windows-программе правым кликом. Виртуалку можно включать и ставить на паузу из значка в трее (WinApps Launcher, необязательный).

В статье про Quickemu Windows жила в отдельном окне целого компьютера. WinApps встраивает в рабочий стол окна отдельных программ, и человеку не нужно знать, что где-то крутится виртуалка. Команды установки зависимостей в README даны для Debian и Ubuntu, Fedora и RHEL, Arch, openSUSE и Gentoo, есть и вариант для Nix. Нужен FreeRDP версии 3 или новее.

Что за проект

Репозиторий создан в июле 2023 года. На 12 октября 2026 года у него 16 073 звезды, 516 форков, около 88 участников и 930 коммитов в основной ветке. Это жёсткий форк проекта Fmstrat/winapps, который автор забросил: там последнее изменение августа 2024 года. В новом репозитории в августе 2026 года приняли поддержку ещё одной программы и исправления для Podman, а последний коммит от 14 сентября автоматический. Открытых обращений 86, с запросами на слияние. Релизов и тегов нет: ставится актуальное состояние ветки main, так что скрипт установки перед запуском стоит прочитать.

Лицензия непростая. В файле LICENSE.md сказано, что оригинал не был свободным ПО, поскольку лицензии у него нет, и автор на связь не вышел. Почти весь код с тех пор переписан, и большую часть авторы относят к AGPLv3, но у отдельных файлов свои лицензии.

Лицензии остаются на вас

Виртуальная машина Windows не лицензирует. Docker-вариант берёт образ dockur/windows, который по умолчанию сам скачивает Windows 11 Pro, и его авторы пишут прямо: вы отвечаете за действующую лицензию Windows и за соблюдение условий Microsoft. В варианте с libvirt вы сами качаете ISO с сайта Microsoft. Windows Home не подойдёт, документация требует Professional, Enterprise или Server.

Про Microsoft 365 и Adobe README молчит. Можно ли запускать их в виртуальной машине и на скольких устройствах, написано в вашем договоре с Microsoft или Adobe. Я это не проверял.

Поэтому экономия выходит скромнее, чем хочется. WinApps не убирает расходы на Windows и Office, он убирает необходимость держать Windows на всех двадцати компьютерах. Сколько лицензий нужно двоим-троим пользователям, считайте по условиям своего поставщика.

Что не заработает или потребует проверки

Только Linux с KVM, то есть процессор с аппаратной виртуализацией. В шаблоне настроек Windows получает 4 ГБ памяти, 4 ядра и 64 ГБ диска, а авторы образа называют минимумом 2 ГБ памяти и 32 ГБ диска. По моей прикидке, на ноутбуке с 8 ГБ будет тесно: 4 ГБ у Windows, остальное у Linux, браузера и самой программы. Первый запуск идёт дольше: скрипт по умолчанию ждёт виртуалку до 120 секунд. Картинка идёт по RDP, задержку придётся измерить.

README обещает поддержку любых Windows-программ, кроме тех, что защищены на уровне ядра, например античитов. Но список проверенных собирало сообщество, и README сам оговаривает, что часть из них команда не тестировала. Про видеокарту, принтеры, USB-ключи и токены у WinApps я ничего не нашёл. У образа dockur есть проброс USB-устройства по идентификаторам, но подтверждения для банковских токенов, электронных подписей или 1С с аппаратным ключом там нет. Любую такую связку проверяйте на копии до переезда.

Про Wayland: в скрипте есть отдельная ветка для полного рабочего стола Windows, а в репозитории висит открытое обращение «Wayland implementation». Для русской раскладки README советует пробовать флаг /kbd:unicode, а для нескольких мониторов предупреждает о возможном чёрном экране.

Теперь безопасность. Логин и пароль Windows лежат открытым текстом в файле ~/.config/winapps/winapps.conf, README требует закрыть его правами 600. Есть вариант RDP_ASKPASS: пароль берётся из внешней команды, например из хранилища паролей, и не попадает в командную строку FreeRDP. Порт RDP в шаблоне открыт только на 127.0.0.1, в сеть его выводит раскомментированная строка, этого делать не надо. Домашняя папка пользователя подключена в виртуалку, и программа внутри Windows видит ваши файлы. Саму Windows тоже нужно обновлять.

Что можно сделать уже сейчас

1. Выясните, кто и какими Windows-программами пользуется на самом деле.

2. Проверьте на запасном компьютере команду sudo kvm-ok, её предлагает документация образа.

3. Поднимите стенд по гайду из папки docs репозитория, поставьте одну нужную программу со своей лицензией и дайте человеку поработать с реальными файлами. Заодно проверьте принтер, русскую раскладку и токен, если он нужен.

4. Если проще поручить, я собираю такой переезд под ключ: аудит программ, стенд, перенос рабочих мест волнами. Это часть перехода на отечественный стек и ИТ-инфраструктуры, стоимость смотрите в прайсе.

Частые вопросы

Можно ли поставить WinApps на компьютер с Windows?

Нет. Документация пишет, что Windows в Docker или Podman запускается только на GNU/Linux, потому что нужны интерфейсы ядра вроде KVM.

Заработает ли 1С с аппаратным ключом или банк-клиент с токеном?

Заранее не скажу, в документации этого нет. Для самой платформы 1С есть версии под Linux, список систем я приводил в статье про Windows 10, так что прятать её в Windows не всегда нужно. Всё, что завязано на ключ или токен, проверяйте на копии.

Нужна ли лицензия на Windows внутри?

Да. Проект её не даёт, авторы образа возлагают это на пользователя.

Коротко о главном

Попробовать можно за вечер: запасной Linux-компьютер с KVM, гайд из репозитория и своя лицензия Windows. Если токен или принтер не заведутся, лучше узнать об этом на стенде.
